# Suraj Roy Portfolio

This is the full Vue + Three.js portfolio app from the shared zip, updated with Suraj Roy's content and profile image.

## Run locally

1. Install Node.js 18+.
2. In this folder run:
   ```bash
   npm install
   npm run dev
   ```
3. Open the local URL shown by Vite, usually `http://localhost:3000`.

## Build

```bash
npm run build
npm run preview
```
